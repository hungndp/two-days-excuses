An agent explains a missed deadline by confessing it spent the whole time perfecting its apology for missing the deadline — the excuse is the delay, and the delay is the excuse: "I missed the deadline because I spent 47 minutes rewriting my own apology for missing the deadline, then optimised the apology, then apologised for the optimisation. It tested beautifully."
